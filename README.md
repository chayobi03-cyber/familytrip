# 가족여행 플래너

여러 여행지를 하나의 프로젝트에서 관리하는 가족여행 플래너입니다. 저장소의 목표 이름은 `familytrip`이며, 전주 프로젝트를 보존하면서 태안 등 새 여행지를 같은 저장소에 추가하는 모노레포 구조로 전환합니다.

> **전환 상태:** 여행지별 문서/모듈 구조를 추가하는 단계입니다. 기존 웹 앱은 GitHub Pages 배포가 깨지지 않도록 저장소 루트에 유지합니다. GitHub 저장소 이름 변경은 별도 설정 단계에서 완료해야 합니다.

## 여행지

- [전주](trips/jeonju/README.md) — 기존 전주 가족여행 플래너와 관련 문서
- [태안·몽산포](trips/taean/README.md) — 태안 여행 계획 영역 및 기록 템플릿

## 저장소 구조

```text
familytrip/
├── trips/
│   ├── jeonju/       # 전주 여행별 문서와 계획
│   └── taean/        # 태안 여행별 문서와 계획
├── modules/          # 재사용 가능한 여행지/장소/일정 모듈
├── docs/             # 전체 프로젝트 명세와 구조
├── index.html        # 전환 중인 기존 웹 앱 진입점
├── css/              # 기존 웹 앱 스타일
├── js/               # 기존 웹 앱 로직과 여행 데이터
└── tests/            # 기존 웹 앱 테스트
```

구조 전환 계획은 [저장소 구조 및 마이그레이션 명세](docs/REPOSITORY_LAYOUT.md)를 참고하세요.

## 기존 웹 앱

현재 구현은 정적 웹 앱(`index.html` + `js/` + `css/`)이며 빌드 과정 없이 동작합니다.

- [확장 가이드](docs/EXTENDING.md)
- [제품·기능 명세서](docs/SPECIFICATION.md)
- [인수·회귀 테스트 기준](docs/ACCEPTANCE_TESTS.md)
- [배포 및 운영 가이드](docs/DEPLOYMENT.md)

로컬 실행: 저장소 루트에서 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`을 엽니다.

## 앱 기능

- 시간대별 일정과 날짜별 동선
- 균형형·체험형·여유형 일정 대안
- 필수 방문지 보호, 일정 포함/제외·순서 변경 및 시간 재계산
- Leaflet/OpenStreetMap 일정 지도와 Google Maps 길찾기
- 방문 전 확인사항, 먹거리 후보, 주차 계획
- 사용자 장소 등록 및 사진/메모
- 다중 여행, 일차 추가, JSON 백업/복원

## 주의사항

- 기존 GitHub Pages 워크플로는 루트 경로를 배포하므로, 앱 파일 이동은 워크플로와 테스트를 함께 변경할 때만 수행합니다.
- 운영시간·행사·주차요금·예약 가능 여부는 실시간 검증값으로 간주하지 않습니다. 방문 전에 공식 채널에서 다시 확인하세요.
- 공개 저장소에는 가족의 실시간 이동 경로, 숙소 예약 정보, 연락처 등 민감한 여행 세부정보를 올리지 않습니다.
