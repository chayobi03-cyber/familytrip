# 전주 여행

전주 여행에 관한 일정, 방문지, 인수 메모를 모으는 영역입니다.

## 기존 구현

현재 운영 중인 정적 웹 앱은 배포 안정성을 위해 마이그레이션 기간 동안 저장소 루트에 유지합니다.

- 앱 진입점: [`index.html`](../../index.html)
- 제품·기능 명세: [`docs/SPECIFICATION.md`](../../docs/SPECIFICATION.md)
- 여행지·데이터 추가 가이드: [`docs/EXTENDING.md`](../../docs/EXTENDING.md)
- 테스트: `node tests/engine.test.js`

## 운영 규칙

- 필수 방문지, 방문 순서, 운영시간 등은 계획 데이터와 현장 확인값을 구분합니다.
- 영업/입장 여부, 공연 일정, 주차, 예약 가능 여부는 출발 전에 공식 채널에서 확인합니다.
- 새 공통 기능은 먼저 `modules/`의 작성 규약과 비교해 공통화 여부를 판단합니다.
- 앱 파일을 이 디렉터리로 이동하려면 Pages 워크플로와 상대경로 테스트를 같은 변경으로 수정해야 합니다.
