# 태안·몽산포 여행

태안 여행의 일정 초안, 장소 후보, 준비물, 현장 확인사항을 모으는 영역입니다. 이 문서는 구조 템플릿이며 예약 또는 운영 정보를 실시간 검증한 결과가 아닙니다.

## 권장 구성

- `PLAN.md` — 날짜별 일정 초안 및 이동 순서
- `CHECKLIST.md` — 준비물, 아이 동반 안전사항, 출발 전 확인
- `PLACES.md` — 장소 후보, 공식 출처, 마지막 확인 시각
- `LESSONS.md` — 귀가 후 실제 동선·비용·만족도와 다음 여행 개선점

## 확인해야 할 항목

- 기상특보, 강수·풍속, 해상 상황
- 공식 조석 예보와 갯벌 체험 가능 시간
- 주차 및 현장 진입 방법
- 음식점과 체험시설의 영업·운영 일정
- 숙소 체크인/체크아웃 및 개별 예약 내역(예약 내역은 공개 저장소에 기록하지 않음)

## 기록 규칙

정보마다 출처와 확인 시각을 남깁니다. 예측이나 과거 자료를 실시간 확인값처럼 적지 않으며, 불확실하면 `확인 필요`로 표시합니다. 가족의 구체적인 숙소 예약, 연락처, 실시간 이동 시간표는 공개 저장소에서 제외합니다.
