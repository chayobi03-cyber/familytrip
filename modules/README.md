# 공통 여행 모듈

여러 여행지에서 반복 사용하는 장소/활동/체크리스트를 이 디렉터리에서 관리합니다. 여행 한 곳에만 해당하는 세부 일정은 `trips/<destination>/`에 둡니다.

## 모듈 추가 절차

1. `modules/<module-name>/README.md`를 만듭니다.
2. 모듈의 목적, 적용 조건, 필요한 입력, 결과물, 실패/안전 조건을 기록합니다.
3. 운영시간·가격·예약 등 변동 정보는 공식 출처 URL과 확인 시각을 기록합니다.
4. 재사용이 가능한 데이터와 여행지별 조정값을 구분합니다.
5. 최소 한 가지 예시와 검증 체크리스트를 포함합니다.

## 권장 모듈 템플릿

- **이름 / 버전**
- **목적**
- **적용 조건 및 제외 조건**
- **입력값 / 출력값**
- **장소·활동 데이터** (필요시)
- **사전 확인사항** (출처, 확인 시각 포함)
- **안전 및 접근성 고려**
- **검증 방법**
- **변경 이력**

## 원칙

- 사실, 추정, 사용자 입력을 서로 구분합니다.
- 운영시간·요금·예약·조석·기상처럼 바뀌는 정보는 다시 확인할 수 있게 출처를 기록합니다.
- 개인정보나 가족의 실시간 위치를 공통 공개 모듈에 넣지 않습니다.
